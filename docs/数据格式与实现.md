# 数据格式与版本适配

rc5 候选只支持 NBA 2K27 Windows x64 快速比赛的未加密原生 SYNC RDAT v9。旧加密存档分支已移除；历史格式说明不构成其他游戏或加密存档支持承诺。权利和条款未决事项见独立审阅。

## 当前实现

原生 SYNC 清单是 UTF-8 文本，每行是逻辑路径、数据文件名和长度，通常带结尾 NUL。名单逻辑路径默认 roster/roster.iff；对应文件是单一 roster.RDAT 的 ZIP。数据文件名是内容 MD5 的 8-4-4-4-12 分组。

当前 RDAT 前 16 字节是小端 uint64 长度和版本 9，后续为 BNH/BNDL 容器。每个节点附带结构定义与校验。程序从同一文件解析字段位偏移、长度、数组容量，保持未修改节点、分配容量和记录长度。当前分发功能只导入原生 SYNC/RDAT，不导入个人加密生涯存档。

三张主要表为 PlayerData、TeamData、FreeAgentData。内置档案的位长度分别为 9721、43433、64016。每次构建前同时核对档案中的 30 个球队索引名称；源 ZIP 长度、MD5、节点与结构定义校验均需通过。

## 缺员回退

整队零匹配、无法形成安全首发或容量冲突时，保留更新前整队记录、成员和阵容。相关转会暂缓，必要时联动保护受影响球队，避免重复归属。原队员按游戏原首发角色和本地位置字段补位，不假定数字位置枚举。回读用记录位范围指纹核对原样保留；旧伤停不是当前更新。来源错误、原生数据缺失/损坏仍停止。

## 兼容档案

profiles/nba2k27-rdat-v9.json 记录当前格式、三张表布局和球队名称。高级配置可选择外部 JSON 档案、球队索引映射与伤病枚举。

同一游戏的补丁保留布局与语义时可继续使用。不同版本更改布局、字段语义、球队索引或容器时，需要依据真实原件更新档案或解析器。仅填入新的表位长度不能证明适配完成。应用对未支持容器拒绝导入，对不匹配布局停止写入。

当前只有 NBA 2K27 的上述布局有本机真实同步依据。Steam 路径和启动适配属于运行环境支持，不能代替 Steam 游戏内验证；其他游戏代际也不以“已实现配置选项”冒充已兼容。

## 球员和阵容

球员使用明确姓名规范与别名匹配，优先使用当前 NBA 或自由球员中的唯一真实记录。默认缺员时从本队更新前已有队员补位，保留姓名和完整原记录；严格模式停止，不拿替补改名顶替。SYNC RDAT v9 是游戏数据格式，不是必须另装的补丁。

rc6 从当前已安装、清单状态已认可的名单规划，导入基准只作恢复。更新所属、合同球队、成员数组、人数、自由球员和活跃名单。成员合同类别沿用当前数据；未归类的新成员使用 CorePlayer，当前不根据新闻生成薪资、能力值、模型或球衣号。

出场顺序读取球队 depthcharts 的 PG/SG/SF/PF/C。五位置唯一分配优先保留可用首发，再尽量选择更高深度的球员；替补按最佳深度档次与位置排序，未上表的剩余成员置后。结果写入 LineupPlayer，专项阵容继续保留各自用途并替换失去资格的成员。

伤病通过 ESPN 球员 ID 跨队关联；汇总漏人时使用球队名单的有效状态和日期。不同时间取较新状态，同一时间冲突、未知状态和无效日期停止处理。未提供的诊断细节保持未知。

| 字段 | 当前读取宽度 |
| --- | --- |
| InjuryType1 / InjuryType2 | 8 位 |
| InjuryStatus1 / InjuryStatus2 | 3 位 |
| 第一时长字段（hash 1956514736） | 20 位 |
| 第二时长字段（hash 3986119178） | 20 位 |

状态 Healthy/Active=0、Probable=1、Day-To-Day/Questionable=2、Doubtful=3、Out/Suspension=4。Suspension 类型为内置枚举 116，和伤病 Out 在来源选择时仍区分。仅来源实际更新球员清空第二伤病槽；回退保留者两槽原样保留，新生成阵容排除任一槽 Out/停赛者；左右侧仅记日志；时长按预计回归 UTC 日期差换算分钟。未知部位的类型 0 与非零状态在游戏内如何呈现，仍需对应游戏版本确认。

## 提交与恢复

1. 确认游戏关闭，读取不可变基准并抓取来源。
2. 在配置的缓存盘生成名单，回读三张修改表、人数、引用、出场顺序及 ZIP 校验。
3. 校验目标仍为基准或本工具上次成功提交的清单，并绑定实际 SYNC 路径。
4. 备份旧清单，写入新内容 MD5 文件，最后替换清单并保存成功记录。
5. 成功后清理来源缓存；失败保留现有清单和已有诊断材料，阻止启动。

可捕获的提交错误恢复旧清单；断电和强行终止没有跨文件完整事务保证。恢复入口重新引用导入的原始清单，保留已有数据文件与个人存档。
