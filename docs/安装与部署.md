# 安装与部署

## 交互安装

运行 Windows x64 安装包，选择目录及桌面快捷方式。安装无需管理员权限，自带 Python/Tk/psutil。结束后可打开配置界面；安装程序不会自动启动或修改游戏。

桌面快捷方式为“更新并启动”；开始菜单另有配置入口。首次只需选择游戏；工具自动寻找、校验已有名单并在保存时建立恢复备份，之后进入首页更新。内部目录收在折叠的高级设置。

## 便携版

解压 portable.zip 后保持整个目录完整，运行 Roster-Beacon.exe。_internal 目录是随附运行环境，不能只复制 EXE。Roster-Beacon-cli.exe 为控制台入口。

## 静默部署

```powershell
.\Roster-Beacon-1.0.0-rc9-windows-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\Apps\Roster Beacon"
```

这只安装工具。不同电脑的游戏路径和本机基准仍需首次配置；可以事先部署用户自己的配置 JSON，并设置 NBA_ROSTER_SYNC_CONFIG 指向它。配置和名单数据均不随公共安装包下发。

## Steam

自动发现读取 Steam 注册表、libraryfolders.vdf 和 appmanifest_*.acf，获取本机真实 App ID；检查常见 userdata/<账号>/<AppID>/local 或 remote 下的 SYNC 路径。现有配置或唯一明确结果自动选中；多个候选由用户选择，显示保存时间，不单凭时间决定覆盖目标。选择 EXE 后同样探测本机已有名单。未发现数据时提示先进入游戏主菜单再退出重新查找，无需新建目录；高级设置仍可选择已有数据位置。

Steam 游戏按原生 steam://rungameid/<AppID> 协议启动。工具保持 Steam Cloud 设置原样，也不修改 remotecache.vdf。Cloud、游戏启动或退出可能同步相关文件，因此 Steam 实机加载仍需 review；检测到清单外部变更时停止覆盖。

Steam Cloud 的实际保存位置由各游戏配置，不能把所有游戏的数据假定在同一目录。参考：https://partner.steamgames.com/doc/features/cloud 。

## 升级和卸载

升级安装会替换程序文件；用户设置、数据、基准与备份独立保留。卸载只移除已安装的工具文件和快捷方式，保留这些恢复材料。

要撤销名单修改，在游戏关闭时使用“恢复导入的基准名单”。恢复的是该工具导入时的版本，不会通过联网获取另一份 2K 官方文件。

## 发布文件

- setup.exe：安装程序。
- portable.zip：完整便携目录。
- source.zip：公开源码白名单导出。
- SHA256SUMS.txt：下载校验。
- release-manifest.json：版本、源码提交和构建交付物摘要。
