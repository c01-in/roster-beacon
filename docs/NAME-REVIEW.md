## Names to avoid prioritizing

- **Roster Sync** is generic and already appears as [an unrelated GitHub repository](https://github.com/vzauartcc/roster-sync), increasing search ambiguity.
- **Lineup Bridge** was initially shortlisted, but checking the hyphenated slug found the existing public repository [zohaf/lineup-bridge](https://github.com/zohaf/lineup-bridge). It is removed from the recommended shortlist even though the joined-name search had no match.
- **CourtRelay** has an existing company-name record, COURTRELAY LIMITED, in [The Gazette's published company filings](https://www.thegazette.co.uk/London/issue/900487/supplement/1433/data.pdf). That is not proof of a conflicting software trademark, but it makes it a less clean naming choice.
