本轮没有新增或运行自动化测试，没有启动游戏、覆盖名单、操作用户桌面或确认游戏内效果。异常响应、完整诊断报告与本机路径均保留在私有诊断目录，不进入公开仓库或发布包。

## 2026-11-02：用户授权的本机完整使用流程

用户明确要求在本机卸载、重装并走真实流程。本次使用 1.0.0-rc1 实际安装包，安装到 E 盘，所有安装/卸载退出码均为 0；先前没有安装记录，因此先安装再执行卸载和重装。

已从重装后的 GUI 填写真实游戏和 SYNC 路径，读取并选择原生清单，保存配置、导入基准，再点击“同步并启动游戏”。实际更新成功：30 队、来源 521 人、写入 516 人、92 条伤病。置顶窗口显示湖人上一场对猛龙、当前对热火、下一场对国王；确认后实际启动游戏。

游戏正常进入离线快速比赛选队画面。画面中的湖人首发为 Luka Dončić、Austin Reaves、Ziaire Williams、Matisse Thybulle、Walker Kessler，与本次同步报告的前五名一致。随后从游戏菜单正常退出，结束图形负载。

还实际核对了以下分支：

- 从 GUI 恢复基准，清单 SHA256 恢复为导入时的原值。
- 临时设置无效的来源地址，真实 HTTP 错误触发可见错误提示、failed_blocked_launch 与 game_launched=false，目标清单保持原样；已还原正常配置。
- 恢复来源并重新同步成功，在赛程窗口点取消，记录 cancelled_by_user，游戏保持关闭。
- 配置完成后再次卸载、重装：程序文件被移除，配置和基准保留且哈希一致；重开安装版后，GUI 实际显示原配置。
- 来源缓存成功后已删除；安装临时文件按任务收尾清理。

本轮没有新增测试脚本，也没有声称覆盖所有场景。验证对象为本机独立安装的 NBA 2K27；Steam 版、其他游戏代际、完整对局及所有伤病表现尚未实机验收。安装过程的个人路径、原生名单备份和日志只保存在本机诊断目录，不放入公开包。
