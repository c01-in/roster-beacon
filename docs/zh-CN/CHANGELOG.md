# 更新记录

## 1.0.0-rc10 — 2026-11-03

游戏或补丁改动同一存档位置的名单后，自动校验当前名单、生成并回读验证、保存完整清单和名单恢复副本，再正常提交。保留最初恢复基准及旧备份。数据无效或不兼容、存档绑定不同、备份失败、游戏运行以及同步期间文件变化仍停止。日常补丁无需用户手动重新读取；中英文应用说明同步更新。

## 1.0.0-rc9 — 2026-11-03

修复来源深度表缺位置时整次更新被阻止的问题（实际掘金响应只有 PF/C）。默认利用球员真实本地位置、原首发位置映射和原出场顺序补全缺位，安全规划成功的球队继续更新转会和伤病；无法安全补全时整队保留，关联转会暂缓。同位置重复条目按首次出现去重。球队或赛季不符、无效球员、整张深度表缺失及严格模式缺位仍停止更新。中英文回退详情明确展示缺少位置。异常来源响应失败时保留，成功提交后自动清理。

## 1.0.0-rc8 — 2026-11-03

- 设置改为选择游戏、自动查找校验已有名单、保存并开始使用；内部目录及版本适配默认折叠。
- Steam 和手动选 EXE 使用同一探测入口；多份名单显示保存时间，由用户明确选择，不按时间擅自覆盖。
- 普通设置保存保留原恢复备份；主动重新导入或更换绑定建立新备份，旧副本继续保留。
- About 的权利人联系使用固定可点击链接，创建仓库即可使用同一应用包，无需公开后再构建一版。
- 已对本机现有文件做只读探测，未操作桌面、启动游戏或运行自动化应用测试。
