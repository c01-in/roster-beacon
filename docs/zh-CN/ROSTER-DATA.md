# 名单数据与缺少球员

**[English](../ROSTER-DATA.md)** | **简体中文**

基准提供游戏内真实球员记录和原生表结构；每日来源提供球队、伤病和出场顺序。联网获取当天信息不会创建基准里没有的球员。

代码不依赖指定网盘包，但需要兼容的 **NBA 2K27 未加密原生 SYNC RDAT v9** 名单和清单。校验只证明结构/完整性，不证明来源和授权。

**RDAT v9 是格式，不是另装的包。** 可以使用游戏已有的兼容原生名单。默认缺员时从本队现有真实队员补位，保留他们的身份、姓名和原数据；已知 Out/停赛者不进入新生成阵容。整队零匹配、无法凑出安全首发或容量冲突时，保留本次更新前游戏实际名单中的整队记录与出场顺序，不退回最早的恢复基准。

整队保留会暂缓相关转会，必要时连带保护其他队，防止跨队重复。整队旧伤停也是旧快照，不算更新成功的伤病信息。覆盖记录会列出补位、保留和暂缓项。来源失败、数据损坏或缺少可读原始名单仍停止；严格模式也仍在缺员时停止。

## 可选的名单包流程（用于补齐真实记录）

1. 正常退出游戏，保留当前 SYNC 和恢复材料。
2. 取得游戏提供的兼容更新，或你有权使用的名单包，核对实际许可、目标版本、所需资产及安装步骤。“官方”“免费”不是转发授权。
3. 按游戏或作者支持的方式安装。工具不安装任意 ZIP、EXE、注入器、面补或模型。
4. 打开“维护 → 原生名单与回退说明 → 前往设置”，选择游戏并重新查找已有名单；展开“高级设置”，勾选“重新读取当前游戏名单并建立恢复备份”，再点“保存并开始使用”。
5. 再运行“仅更新名单”，检查覆盖情况和未匹配球员。

导入验证原生清单、引用文件、长度、哈希、容器和布局，并保存不可变本地基准。导入不获取当天数据，也不启动游戏；旧备份继续保留。

兼容名单确实包含新增球员的唯一记录时，重新导入后可参与下一次匹配。未知布局和加密存档会停止。只有姓名、别名、照片、面补、模型或动作不能替代缺少的记录；工具不改名顶替、不虚构属性来达到完整匹配。

## 缺员和公开边界

首页是**上次成功更新**的覆盖记录，不代表未同步的新基准。未匹配可能是记录缺失、姓名歧义或不符合匹配规则。默认显示原队员补位或整队保留情况；严格模式阻止更新。

仓库和安装包不附带名单、二进制补丁、模型、存档、网盘链接、提取码或凭据。旧开发包没有核实再分发授权，不作为公开依赖。改成差分格式不自动产生授权。详见[独立审阅](../legal/RISK-REVIEW.md)。
