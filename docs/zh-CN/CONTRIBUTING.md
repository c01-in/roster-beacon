# 贡献方式

**[English](../../CONTRIBUTING.md)** | **简体中文**

当前只支持 NBA 2K27 Windows x64 快速比赛及未加密原生 SYNC RDAT v9。公开修改需同时维护中英文 README，并先核实新增数据或代码的许可。权利未决事项见[独立审阅](../legal/RISK-REVIEW.md)。

修改前阅读[数据格式与实现](../数据格式与实现.md)。维护流程采用有针对性的人工检查和真实构建/运行证据，不新增或运行自动化测试，不声称未执行的检查已通过。

版本适配必须依据真实文件的内嵌结构与字段语义，说明适配范围及未确认的游戏效果。不要通过关闭完整性检查、改其他球员姓名或虚构来源数据来获得成功状态。

公开修改与 issue 只附脱敏摘要，保持游戏文件、个人配置、保存路径和 Steam 账号资料在本机。新增运行依赖应固定版本并更新第三方许可。

本地构建参见 README。源码包由明确白名单生成；新增公开文件时同步 scripts/package_release.py，避免遗漏或夹带私人文件。
