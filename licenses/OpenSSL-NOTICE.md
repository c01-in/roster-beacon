# OpenSSL runtime attribution

The reviewed local Windows runtime includes **OpenSSL 3.0.16 (11 February 2025)** for Python HTTPS/TLS. OpenSSL is developed by the OpenSSL Project and its contributors under Apache License 2.0; applicable copyright and attribution notices remain theirs.

`OpenSSL-3.0.16-LICENSE.txt` is the unmodified license from the official tagged source:
https://github.com/openssl/openssl/blob/openssl-3.0.16/LICENSE.txt

Python's combined license is preserved separately. For a different build runtime, the packager obtains the matching small license text from the official OpenSSL tag and records the actual component version. This is a build-time license step, not executable auto-update behavior.
