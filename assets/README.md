# Original UI artwork / 原创界面素材

The small basketball mark in `ui_theme.py`, `app.svg` and `app.ico` are original project geometry, published under the project's MIT license. They use no downloaded images, embedded fonts, player likenesses, league or team logos. Retain the MIT license when redistributing.

The application renders a compact basketball mark in the sidebar with Tk Canvas. The old application hero/court artwork and its rendering code were removed in rc3. `app.svg` and `app.ico` are generated by `scripts/build_assets.py`.

## README artwork

The following documentation assets are original, source-authored SVG geometry and typography under the project's MIT license:

| File | Purpose |
| --- | --- |
| `readme/hero.svg` | Compact dark brand banner with abstract court lines and the application's lime/cyan palette |
| `readme/download-installer.svg` | Linked Windows-installer download action |
| `readme/download-portable.svg` | Linked portable-ZIP download action |

These SVGs have no external images, embedded fonts, scripts, league/team marks or player likenesses. Their system-font lists are fallbacks, not bundled font files. The court geometry is decorative and the “30 teams” label describes supported scope; the banner is not an application screenshot or a sync-result display. The README artwork does not add a banner to the application UI.

Application screenshots, when present, have their capture version, state and privacy treatment documented separately. They are not generated or reconstructed by the SVG artwork.
