# Original UI artwork / 原创界面素材

The small basketball mark in `ui_theme.py`, `app.svg` and `app.ico` are original project geometry, published under the project's MIT license. They use no downloaded images, embedded fonts, player likenesses, league or team logos. Retain the MIT license when redistributing.

The application renders a compact basketball mark in the sidebar with Tk Canvas. The old hero/court artwork and its rendering code were removed in rc3. `app.svg` and `app.ico` are generated by `scripts/build_assets.py`.

侧栏的小篮球和应用图标为本项目原创，以 MIT 许可公开。rc3 已删除大幅宣传横幅、球场素材和对应绘图代码。界面没有下载或使用球队标志、球员照片和授权不清的外部图片。系统字体由 Windows 提供，发布包没有附带字体文件。
